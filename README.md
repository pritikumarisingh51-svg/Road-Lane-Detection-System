# Road Lane Detection System 🚗

## 📌 Overview
This project detects and highlights road lane lines using Computer Vision techniques with Python and OpenCV.

It is useful for understanding the basics of autonomous vehicle navigation and image processing.

---

## 🚀 Features
- Detects road lane lines
- Highlights lanes on road images
- Uses edge detection and Hough Transform
- Beginner-friendly Computer Vision project

---

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

---

## ▶️ How to Run

### Install dependencies
pip install opencv-python numpy matplotlib

### Run project
python lane_detection.py
